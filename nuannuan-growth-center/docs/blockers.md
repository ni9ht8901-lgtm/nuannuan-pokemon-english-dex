# 阻塞项清单

当前本地可先完成扫描、登记、SDK、后台和试点接入。以下事项需要外部账号或真实设备权限后才能完成最终验收。

1. GitHub 授权：用于扫描个人账号和组织仓库、创建改造分支、提交 PR、读取部署工作流。
2. Supabase 项目：需要项目 URL、Anon Key、Service Role Key，以及允许执行数据库迁移的权限。
3. Vercel 或现有部署平台授权：用于部署管理后台和同步部署状态。
4. 真实设备验证：需要在 iPhone、iPad、电脑上分别登录同一家庭空间后测试云同步。
5. 线上旧项目清单：本地当前只发现工作区内项目；GitHub 私有仓库或其他本地目录需要授权访问后继续扫描。

处理原则：等待上述权限时，不停止本地建设；所有无法真实完成的项目会保持在“缺少权限”或“仅完成档案收录”状态。
